Современный, быстрый и адаптивный сайт-каталог для презентации и продажи изделий собственного производства (мангальные зоны, садовые качели, беседки, шкафы-купе, кухни, рабочие зоны и др.).

## 🚀 Как открыть и посмотреть сайт

1. **Простой способ (в любом браузере):**
   - Перейдите в папку `C:\Users\Technolog-3\.gemini\antigravity\scratch\masterskaya-uyuta\`
   - Дважды кликните по файлу **`index.html`** — сайт откроется в вашем браузере (Chrome, Яндекс, Edge и др.).

2. **Через локальный веб-сервер (рекомендуется для проверки на телефоне через Wi-Fi):**
   - Откройте PowerShell в папке проекта и запустите:
     ```powershell
     python -m http.server 8080
     ```
   - Откройте в браузере: `http://localhost:8080`

## ⚙️ Как настроить контакты, цены и ссылки

Все настройки сайта и каталог изделий находятся в **одном файле**:
👉 **`products.js`**

### 1. Изменение контактов (в начале файла в блоке `SITE_CONFIG`):
```javascript
const SITE_CONFIG = {
  brandName: "Мастерская Уюта",
  tagline: "Мебель из ЛДСП и профильной трубы на заказ по вашим размерам",
  location: "Кировград — Невьянск, Свердловская область",
  phone: "+7 (900) 000-00-00",               // Ваш реальный телефон
  phoneLink: "tel:+79000000000",             // Телефон для звонка (без пробелов)
  telegramUsername: "@masterskaya_uyuta",    // Имя пользователя в Telegram
  telegramUrl: "https://t.me/ваш_логин",      // Ссылка на Telegram
  avitoUrl: "https://www.avito.ru/...",      // Ваша страница на Авито
  maxMessengerUrl: "https://max.ru/...",     // Ссылка на мессенджер MAX (когда будет готова)
  ...
};
```
*Когда ссылка на MAX будет готова, просто вставьте её в параметр `maxMessengerUrl` — все кнопки сайта начнут сразу открывать ваш чат в MAX.*

### 2. Изменение цен или описаний товаров:
В этом же файле `products.js` в массиве `PRODUCTS` найдите нужное изделие и измените поле `priceFrom`:
```javascript
{
  id: "swing-comfort-loft",
  title: "Садовые качели «Комфорт Loft» с навесом",
  priceFrom: "27 900", // Поменяйте на любую сумму
  shortDesc: "...",
  ...
}
```

## 📁 Структура проекта

- **`index.html`** — разметка сайта, структура блоков, шапка, калькулятор, FAQ, подвал и модальные окна.
- **`style.css`** — дизайн в стиле светлого скандинавского минимализма с элементами лофта, мобильная адаптация, анимации.
- **`products.js`** — каталог 14 позиций с описаниями, характеристиками, стартовыми ценами и конфигурацией контактов.
- **`app.js`** — интерактивная логика: фильтры категорий, поиск, модальная фотогалерея со слайдером, расчет размеров в мессенджеры.
- **`images/products/`** — 31 оптимизированная фотография изделий (все фото сгруппированы по позициям каталога).

## 🌐 Как опубликовать сайт в интернете

Сайт полностью статичный (HTML + CSS + JS) и не требует базы данных или сервера:
1. **Бесплатный хостинг:**
   - **GitHub Pages:** загрузите файлы в репозиторий и включите Pages в настройках — сайт сразу станет доступен по всему миру.
   - **Vercel / Netlify:** перетащите папку проекта в окно браузера и получите готовый адрес через 10 секунд.
2. **Обычный хостинг (Beget, Timeweb, Reg.ru):**
   - Загрузите все файлы из папки в `public_html` через панель хостинга или FTP.
